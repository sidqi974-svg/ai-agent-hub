# AI Agent Hub (Telegram Style & 9Router)

Web app AI agent lokal dengan gaya antarmuka Telegram modern, terintegrasi dengan model **Gacor** & **9Router**, dilengkapi editor workflow n8n-style dan web clipper.

## Cara Menjalankan di PC / Laptop:
1. Pastikan Python terinstal.
2. Jalankan server lokal di folder project:
   ```bash
   python -m http.server 8080
   ```
3. Buka browser di: `http://127.0.0.1:8080/index.html`

## Cara Akses dari HP (Mobile):
1. Pastikan PC dan HP berada dalam satu jaringan WiFi yang sama.
2. Cek IP lokal PC (contoh: `ipconfig` di Windows -> IPv4 Address misal `192.168.1.x`).
3. Buka di browser HP: `http://<IP_PC>:8080/index.html`
